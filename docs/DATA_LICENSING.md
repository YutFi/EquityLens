# Data licensing notes

This is a summary for contributors, not legal advice.

- **Imported data stays on the user's device.** EquityLens does not upload it. The user is responsible for having the right to use any file they import.
- **Do not commit vendor data to this repository** unless the licence explicitly permits redistribution. Many exchanges and vendors forbid it, including for "free" delayed data.
- **Synthetic demo data** is generated by the app (fictional names, seeded PRNG) and carries no third-party rights.
- **Seed directory** contains only public facts (stock code and company name), compiled by hand, unverified, and not a substitute for the official listing.
- **Charts**: TradingView Lightweight Charts is Apache-2.0 and requires attribution, which the app shows. Keep the notice if you modify the chart component.
- **Branding**: EquityLens uses an original design. Do not copy other products' logos, layouts or proprietary assets.

Before adding any provider, record its terms (use, rate limits, redistribution, attribution) in `docs/DATA_PROVIDERS.md` and `src/data/providerCatalog.ts`.
